# 🗜️ Huffman CLI Archiver

Консольный архиватор файлов, реализующий **алгоритм Хаффмана** для сжатия данных без потерь. Написан на чистом C с использованием стандартной библиотеки. Проект включает в себя не только сам алгоритм, но и интерактивный интерфейс, подробную аналитику производительности и встроенный фреймворк для автоматического тестирования.

## ✨ Особенности

- **Алгоритм Хаффмана:** Эффективное кодирование символов переменной длиной бинарного кода.
- **Сохранение метаданных:** Архиватор "помнит" оригинальное расширение файла и его точный размер.
- **Оптимизированный I/O:** Отказ от `fgetc`/`fputc` в пользу буферизированного чтения/записи порциями по 4 КБ (`fread`/`fwrite`), что минимизирует количество системных вызовов.
- **Кроссплатформенность:** Корректная работа в Windows (с настройкой UTF-8 консоли), Linux и macOS.
- **Интерактивное меню:** Поддержка drag-and-drop путей, автоматическая очистка кавычек и слэшей, защита от случайной перезаписи файлов.
- **Детальная аналитика:** Вывод времени работы каждого этапа алгоритма (подсчет частот, построение дерева, сжатие) и коэффициента сжатия.
- **Встроенный Автотест:** Генерация 100 случайных файлов 7 различных типов с последующей проверкой целостности и сохранением статистики в CSV.

## 🏗️ Архитектура и формат файла

### Формат `.huf`
Сжатый файл имеет расширение `.huf` и следующую структуру:
1. **Оверхед (Заголовок):** ~2 КБ.
   - Оригинальное расширение файла (до 32 байт).
   - Точный размер исходного файла в байтах (8 байт).
   - Таблица частот всех 256 символов ASCII (2048 байт). *Это позволяет восстановить дерево Хаффмана при распаковке без хранения самого дерева в файле.*
2. **Тело:** Побитово упакованные данные исходного файла.

### Модули
- `main.c` — точка входа, настройка локали и кроссплатформенности.
- `interface.c` — консольное меню, валидация путей, взаимодействие с пользователем.
- `compressor.c` — логика сжатия, подсчет частот, генерация кодов.
- `decompressor.c` — логика распаковки, обход дерева Хаффмана.
- `huffman_tree.c` — построение дерева с использованием алгоритма на двух очередях (сложность $O(N)$ для алфавита 256).
- `analytics.c` — профилирование и расчет метрик.
- `autotest.c` — стресс-тестирование алгоритма.

## 🚀 Сборка и запуск

### Требования
- Компилятор C (GCC, Clang или MSVC).
- Make (опционально, для удобной сборки).

### Вариант 1: С помощью Make
Создайте файл `Makefile` в корне проекта со следующим содержимым:
```makefile
CC = gcc
CFLAGS = -Wall -Wextra -O2
SRC = main.c interface.c compressor.c decompressor.c huffman_tree.c analytics.c autotest.c
OUT = huf_archiver

all: $(OUT)

$(OUT): $(SRC)
	$(CC) $(CFLAGS) -o $(OUT) $(SRC)

clean:
	rm -f $(OUT) *.o
```
Затем выполните в терминале:
```bash
make
./huf_archiver
```

### Вариант 2: Ручная компиляция (GCC/Clang)
```bash
gcc -O2 -Wall -o huf_archiver main.c interface.c compressor.c decompressor.c huffman_tree.c analytics.c autotest.c
./huf_archiver
```

## 🖥️ Использование

При запуске программы открывается интерактивное меню:

```text
========== АРХИВАТОР ЗАПУЩЕН ==========
Добро пожаловать в архиватор!

================ МЕНЮ ================
Выберите действие:
1. Сжать файл
2. Распаковать файл
3. Запуск автотеста
0. Выход
```

### Сжатие и Распаковка
1. Выберите `1` (Сжать) или `2` (Распаковать).
2. Введите путь к файлу (можно просто **перетащить файл** в окно терминала).
3. Если файл с итоговым именем уже существует, архиватор предложит:
   - `y` — перезаписать;
   - `n` — отменить;
   - `r` — ввести новое имя.
4. После завершения программа выведет **отчет об аналитике** (размеры файлов, коэффициент сжатия, время выполнения в секундах).

### Автотест (Пункт 3)
Запускает генерацию 100 тестовых файлов 7 типов:
1. Пустой файл
2. Файл размером 1 байт
3. Файл из одного символа
4. Файл из двух символов
5. Файл с равномерным распределением (Random)
6. Файл с неравномерным распределением (Uneven)
7. Файл со всеми 256 символами ASCII

Все файлы сжимаются, распаковываются и побайтово сравниваются с оригиналом. Результаты (время, размеры, статус) сохраняются в файл `./autotest_files/autotest_data.csv` (совместим с Excel).
